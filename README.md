# AP_TI1125070_Arfel-Ardiya-Pratama

Nama : Arfel Ardiya Pratama

NIM  : TI1125070

Kelas: TI12D

Di sini saya menyelesaikan studi kasus untuk membuat sebuah program kasir sederhana berbasis C++. Tugas utama dari program ini adalah mengelola transaksi penjualan, mulai dari memunculkan daftar produk yang dijual, mencatat apa saja yang dibeli oleh pelanggan, sampai otomatis menghitung total harga, pajak, dan potongan diskonnya. Di akhir sesi, program akan langsung mengeluarkan struk belanjaan lengkap dengan tanggal transaksinya. Selain itu, program ini juga sudah bisa melayani pembelian banyak barang sekaligus dalam satu kali jalan dan punya fitur untuk mengulang transaksi baru.

𝗙𝗶𝘁𝘂𝗿 𝗨𝘁𝗮𝗺𝗮

Bisa memunculkan daftar barang yang tersedia.

Otomatis menjumlahkan subtotal dan total bayar belanjaan.

Sudah dilengkapi perhitungan pajak belanja.

Bisa memotong harga secara otomatis jika ada diskon.

Bisa mencetak struk pembelian yang rapi.

Mendukung pembelian beberapa jenis barang sekaligus dalam satu nota.

Menampilkan info tanggal kapan transaksi tersebut dilakukan.

Dilengkapi menu untuk mengulang atau membuat transaksi baru tanpa harus keluar dari program.

𝗣𝗲𝗻𝗲𝗿𝗮𝗽𝗮𝗻 𝗞𝗼𝗻𝘀𝗲𝗽 𝗖𝗼𝗱𝗶𝗻𝗴 (𝗖++)

Dalam menyusun kode program ini, saya menerapkan beberapa konsep dasar pemrograman seperti:

Prosedur tanpa parameter dan Prosedur dengan parameter untuk merapikan bagian-bagian kode (seperti fungsi cetak menu atau struk).

Fungsi dengan parameter serta Fungsi dengan nilai balik (return value) untuk menangani perhitungan matematis (seperti rumus total, pajak, dan diskon).

Logic Percabangan (if dan switch) untuk menentukan pilihan menu, jenis barang, dan kondisi diskon.

Perulangan (do-while) agar kasir bisa terus menginput barang atau mengulang transaksi selama diinginkan.

Array untuk menyimpan daftar nama barang, harga, dan keranjang belanjaan user agar datanya terstruktur.
